# Retired Compatibility Links

All temporary compatibility symlinks were retired after code, configuration, and runnable command documentation were migrated to canonical paths.

- Scripts: `scripts/data/`, `scripts/eval/`, `scripts/utilities/`
- Results: `results/`
- Figures: `figures/`
- Logs: `logs/`
- Perturbations: `perturbations/`
- Checkpoints: `models/checkpoints/`

The former link-to-target mappings and hashes are retained under `_project_inventory/post_physical_organization/` for rollback and audit.
