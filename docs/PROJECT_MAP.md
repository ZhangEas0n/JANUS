|---|---|---|

| `models/` | Model index and organized task heads/checkpoints | active |
| `perturbations/` | Categorized Original and Mel-Mimic perturbations | active canonical location |
| `results/` | Canonical categorized experiment outputs | active |
| `figures/` | Future categorized figures | no historical files moved |
| `recordings/` | OTA/calibration recordings | no historical recordings found |
| `logs/` | Existing runtime logs plus future train/eval/archive areas | existing files unchanged |
| `docs/` | Project paths, map, plans, prompts, naming rules | active governance docs |
| `archive/` | Source backups and retained legacy material | active rollback record |
| `_project_inventory/` | Before/after audits and validation evidence | retained |
